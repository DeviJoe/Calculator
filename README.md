# Calculator

## Описание алгоритма
1) Так как мы считаем, что все операции
априори долгие, то не пытаемся вычислить те,
которые не используются для вывода
переменных или для вычисления переменных,
которые будут выводиться. Такие операции
должны быть отброшены.
2) Мы должны проверить список операций до
их исполнения на правило, что в одну и 
ту же переменную не может быть повторно
записано значение.
3) Формируется список из выводимых аргументов.
