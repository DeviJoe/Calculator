# Описание алгоритма

## Общее описание
Главный принцип алгоритма - построение дерева. Каждое выражение
состоит из левой и правой части. Если значение не вычислено - туда
передается канал, куда будет передано значение, когда выражение будет 
вычислено. При запуске приложения все выражения запускаются в горутинах.
Если выражению не хватает переменной для вычисления - оно остается в заблокированном состоянии.
Как только вычисленное значение поступает в канал, выражение вычисляется.
Неиспользуемые в дереве выражения не высчитываются.

## Интерфейсы
* **SentenceArgument** - интерфейс аргумента


## Сущности
* **Number** - перелицовка int64. Нужен для того, чтобы
навесить на него интерфейс SentenceArgument. 
Нужно потому что аргументом может быть как строка,
так и число
* **Variable** - переменная, предназначена для хранения
значений. Может печататься, плюс реализует observer - как только
значение вычислено, переменная уведомляет об этом все остальные выражения
* **Sentence** - выражение. Умеет быть вычисленным. Содержит ссылки на левую и правые части
